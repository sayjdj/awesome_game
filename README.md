# The Ultimate UX Hell (궁극의 UX 지옥)

가장 킹받는, 분노를 유발하는 최악의 UX 게임 모음집입니다.

## 기술 스택
- Frontend: Vite + React (Zustand, React Router)
- Backend: Node.js (Express)
- DB/Infra: Docker, Docker-compose

## 스테이지 구성
1. **Stage 1 (최악의 회원가입):** 전화번호를 0부터 99999999까지 슬라이더로 조절하고, 오늘 날짜와 소수가 포함된 기상천외한 비밀번호 규칙을 통과해야 합니다.
2. **Stage 2 (플래피 커서):** 가짜 마우스 커서가 중력의 영향을 받습니다. 마우스 우클릭 점프를 통해 아주 작은 통과 버튼을 정확히 클릭해야 합니다.
3. **Stage 3 (가스라이팅 캡챠):** 캡챠를 무조건 풀어야 하지만, 30% 확률로 무조건 "당신은 로봇입니다" 라며 억지 실패를 유발합니다.
4. **Stage 4 (자본주의 로딩창):** 로딩 게이지가 목적지에 가까워질수록 기하급수적으로 느려집니다(제논의 역설). 현질(결제 버튼)을 해야만 통과할 수 있습니다.

## 실행 방법
```bash
docker-compose up --build
```
이후 `http://localhost:5173` 에 접속하여 고통받으세요.
